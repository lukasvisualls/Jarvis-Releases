# JARVIS 2.1.102

Status: **código preparado / aguardando geração dos binários de distribuição**.

## Alterações desta versão

- organiza o módulo **JARVIS GAMES** em uma estrutura central `games/`;
- registra **Neon Breaker**, **Vice City Web**, **Minecraft 2D** e **Rhythia** no catálogo de jogos;
- formaliza a integração do **Rhythia** com o runtime local do JARVIS no Windows;
- adiciona documentação para inclusão de novos jogos no futuro;
- mantém os jogos web publicados em `public/games/` e preserva o catálogo visual existente.
